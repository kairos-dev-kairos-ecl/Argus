    Create `internal/ingest/handler_auth_mfa.go` with four handlers on `*QueryHandler`:

    - `handleMFAEnroll(w,r)`: requires active JWT (user ID via `auth.UserIDFromContext`); call `auth.GenerateTOTPSecret(user.Email, "ArgusXDR")`; return `{qr_url, secret_base32}`. Do NOT persist yet.
    - `handleMFAVerify(w,r)`: requires active JWT; body `{secret_base32, code}`; call `auth.ValidateTOTPCode`; on success:
      - Fetch KEK: `key, ok := secrets.GetSecret(secrets.KeyMFAEncryption)`. If `!ok` → 500 `{"error":"mfa encryption key not configured"}`.
      - Decode base64 KEK, AES-256-GCM-encrypt the base32 secret, base64-encode the ciphertext+nonce, store to `users.mfa_secret_encrypted`, set `mfa_enabled=true`.
      - Generate 8 backup codes via `auth.GenerateBackupCodes(8)`, insert `HashBackupCode(c)` per row into `user_backup_codes`, return plaintext codes once.
    - `handleMFADisable(w,r)`: requires active JWT; body `{code}`; decrypt stored secret using the same KEK; validate TOTP; on success clear `mfa_secret_encrypted`, set `mfa_enabled=false`, delete unused backup codes.
    - `handleMFAChallenge(w,r)`: PUBLIC — no JWT required. Body `{mfa_token, code?, backup_code?}`. Verify `mfa_token` via `tm.VerifyMFAToken`, look up user by returned ID. If `code` provided decrypt secret and validate TOTP; else if `backup_code` provided look up matching unused hash (constant-time compare via `VerifyBackupCode`), mark `used_at=now()`. On success issue full access token + refresh token + create session (mirror handleLogin response shape exactly).

    Modify `handleLogin` in `internal/ingest/handler_auth.go`: after `AuthenticateUser` succeeds, check `user.MFAEnabled`. If true, issue mfa_token via `tm.IssueMFAToken`, respond `http.StatusAccepted` with JSON `{mfa_required: true, mfa_token: "..."}`, and `return` before the access-token/session branch.

    KEK fetch convention (use everywhere the secret is touched):
    ```go
    key, ok := secrets.GetSecret(secrets.KeyMFAEncryption)
    if !ok {
        http.Error(w, `{"error":"mfa encryption key not configured"}`, http.StatusInternalServerError)
        return
    }
    kek, err := base64.StdEncoding.DecodeString(key)
    if err != nil || len(kek) != 32 {
        http.Error(w, `{"error":"mfa encryption key invalid"}`, http.StatusInternalServerError)
        return
    }
    // ... aes.NewCipher(kek) + cipher.NewGCM(block)
    ```
