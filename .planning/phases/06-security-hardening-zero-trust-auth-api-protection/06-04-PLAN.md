<objective>
Replace raw env-var secrets with an AES-256-GCM encrypted argus.key file. Ship a `argus secrets` CLI for managing it. Keep env-var fallback so existing deployments don't break.

Purpose: Env vars are readable by every process running as the argus user, leak into crash dumps, and spread across ops tooling. An encrypted key file with a single master-key env var (ARGUS_MASTER_KEY) narrows the blast radius and gives ops a proper key-management surface.

Output:
- internal/secrets package: encrypted store + env fallback
- cmd/argus/secrets.go: cobra subcommands registered against the existing rootCmd
- Startup code swapped to GetSecret() for JWT private key, DB password, Redis password

Wave 3 (runs after 06-01 and 06-02) because those two plans also modify cmd/argus/api.go. Serialising here avoids a three-way merge conflict on api.go.
</objective>

New package internal/secrets contracts:

```go
// internal/secrets/store.go
type Store struct { path string; masterKey []byte }

// NewStore returns a Store backed by `path`. If masterKey is nil, reads
// ARGUS_MASTER_KEY (base64-encoded 32 bytes). If env var also empty, returns error.
func NewStore(path string, masterKey []byte) (*Store, error)

// LoadSecrets reads and decrypts the file. Returns empty map if file absent.
func (s *Store) LoadSecrets() (map[string]string, error)

// SaveSecrets encrypts and atomically writes the file (0600 perms).
func (s *Store) SaveSecrets(secrets map[string]string) error

// GenerateMasterKey returns a base64-encoded 32-byte key for ARGUS_MASTER_KEY.
func GenerateMasterKey() (string, error)

// File format on disk (binary):
//   magic (4 bytes: "ARGS") | version (1 byte: 0x01) | nonce (12 bytes) | ciphertext+tag (...)
// Plaintext: gob-encoded map[string]string
```

```go
// internal/secrets/env_fallback.go
// GetSecret returns the value for key, preferring the Store, falling back to os.Getenv.
// If neither has it, returns "", false.
// The package-level Store is set by cmd/argus startup via SetStore().
func GetSecret(key string) (string, bool)
func SetStore(s *Store)
```

    ```go
    package secrets

    import (
        "os"
        "sync/atomic"
    )

    // storePtr holds the active Store (may be nil).
    var storePtr atomic.Pointer[Store]

    func SetStore(s *Store) { storePtr.Store(s) }

    // envAlias maps canonical key → OS env var name for backward compat.
    var envAlias = map[string]string{
        KeyJWTPrivateKey: "ARGUS_JWT_PRIVATE_KEY_PEM",
        KeyDBPassword:    "DB_PASSWORD",
        KeyRedisPassword: "REDIS_PASSWORD",
        KeyMFAEncryption: "ARGUS_MFA_ENCRYPTION_KEY",
    }

    func GetSecret(key string) (string, bool) {
        if s := storePtr.Load(); s != nil {
            if m, err := s.LoadSecrets(); err == nil {
                if v, ok := m[key]; ok && v != "" { return v, true }
            }
        }
        env := envAlias[key]
        if env == "" { env = key }
        if v := os.Getenv(env); v != "" { return v, true }
        return "", false
    }
    ```
