
    Middleware rules:
    - If `r.URL.Path` matches any excluded prefix → call next, no CSRF logic.
    - Safe methods (GET/HEAD/OPTIONS): if `csrf_token` cookie missing, generate token, set cookie `{Name:"csrf_token", Path:"/api/v1/auth", HttpOnly:false, Secure:r.TLS!=nil, SameSite:http.SameSiteStrictMode, MaxAge:12*3600}`. Also set response header `X-CSRF-Token: <token>`. Call next.
    - Unsafe methods (POST/PUT/DELETE/PATCH): read `csrf_token` cookie + `X-CSRF-Token` header. If either missing or constant-time compare fails → `http.StatusForbidden` with `{"error":"csrf validation failed"}`. Else call next.

    Tests using `httptest.NewRecorder` + `httptest.NewRequest`.
