## Security Constraints (Mandatory)

1. $EDITOR temp file: `os.MkdirTemp(homeDir, "argus-rule-*")` — NOT `os.TempDir()`. Dir mode 0700, file mode 0600.
2. $EDITOR launch: `exec.Command(editorBin, tmpFile)` directly — NOT `exec.Command("sh", "-c", ...)`
3. `editorBin` resolved via `exec.LookPath(os.Getenv("EDITOR"))`, fallback vi → nano → notepad
4. Destructive actions (user deactivate, rule disable) require confirm modal before API call
5. No token/password values in any log.Printf or zap.* calls from screen code
6. Grep check at end of task 3: no matches for `os.TempDir()`, `"sh -c"`, or `"Bearer"` in screens/ package
