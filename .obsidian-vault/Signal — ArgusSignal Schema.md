# Signal — ArgusSignal Schema

> The core data atom. Everything in Argus is an `ArgusSignal`.
> Source: `proto/argus/v1/signal.proto` → compiled to `gen/go/argus/v1/signal.pb.go`

## Identity Fields (required)

| Field | Type | Notes |
|-------|------|-------|
| `signal_id` | string | ULID format — time-sortable, generated by SDK |
| `trace_id` | string | UUID v4 — groups signals for one logical operation |
| `span_id` | string | UUID v4 short (8 chars) — one per signal |
| `parent_span_id` | string? | Parent span for hierarchical traces |

## Source (required)

```protobuf
message Source {
  string app_id      // registered application identifier
  string app_version
  string sdk_version
  string environment  // dev / staging / production
  string instance_id  // host or pod identifier
}
```
File: `proto/argus/v1/signal.proto`

## Classification

| Field | Type | Values |
|-------|------|--------|
| `layer` | `Layer` enum | L1_HARDWARE(1) → L10_APPLICATION(10), L_DECISION(11) |
| `category` | string | See [[Signal — ArgusSignal Schema#Signal Categories]] |
| `severity` | `Severity` enum | INFO(1) LOW(2) MEDIUM(3) HIGH(4) CRITICAL(5) |

## Temporal

| Field | Type | Notes |
|-------|------|-------|
| `timestamp` | int64 | Unix nanoseconds — DateTime64(9) in ClickHouse |
| `duration_ms` | float? | Optional operation duration |
| `ingested_at` | int64 | Set by server on receipt — DateTime64(3) |

## Layer Context (`oneof context`)

Only ONE of these is populated per signal:

### L1 — Hardware (`ContextL1`)
```
cpu_percent, memory_used_mb, memory_total_mb, gpu_utilization_pct,
gpu_memory_used_mb, disk_io_read_mbps, disk_io_write_mbps, network_rx_mbps, network_tx_mbps
```

### L2 — Model Weights (`ContextL2`)
```
model_id, model_hash, quantization, size_bytes, load_time_ms,
framework (PYTORCH/GGUF/ONNX/TENSORRT), device
```

### L3 — Tokenizer (`ContextL3`)
```
input_token_count, max_output_tokens, output_token_count,
truncated (bool), vocab_size, tokenizer_name
```

### L4 — Transformer (`ContextL4`)
```
attention_entropy, kv_cache_hit_rate, kv_cache_size_mb,
layer_activations_hash, hidden_state_norm, num_layers, num_heads
```

### L5 — Output Decoding (`ContextL5`) ← richest
```
operation, output_token_count, input_token_count, total_token_count,
finish_reason (STOP/LENGTH/TOOL_CALL/CONTENT_FILTER),
temperature, top_p, top_k, frequency_penalty, presence_penalty,
logprobs[], mean_logprob, top_logprob,
ttft_ms (time-to-first-token), tps (tokens-per-second),
stop_sequences[]
```

### L6 — Safety (`ContextL6`)
```
safety_score, policy_violated, action_taken,
categories_checked[], blocked_content_hash
```

### L7 — RAG/Retrieval (`ContextL7`)
```
operation (SEARCH/EMBED/RERANK/FETCH),
query_text, query_embedding[],
results_count, similarity_scores[],
top_chunk_source, embedding_model, vector_index,
LatencyBreakdown { embed_ms, search_ms, rerank_ms, total_ms }
```

### L8 — Agents (`ContextL8`)
```
operation (TOOL_CALL/PLANNING/DELEGATION/MEMORY_READ/MEMORY_WRITE),
tool_name, tool_arguments (map<string,string>), tool_result,
step_number, agent_id,
permissions_used[], permissions_requested[],
data_flow_tags[]
```

### L9 — API Gateway (`ContextL9`)
```
method (GET/POST/...), path, status_code, latency_ms,
request_size_bytes, response_size_bytes,
upstream_host, client_ip, user_agent,
rate_limited (bool), cache_hit (bool)
```

### L10 — Application (`ContextL10`)
```
event_type (SESSION_START/USER_MESSAGE/COMPLETION/ERROR/FEEDBACK),
component, session_id, conversation_id,
user_message_hash, response_hash, feedback_score,
user_id, org_id
```

### L_DECISION — Policy Decision (`ContextLDecision`)
```
Decision (ALLOW/DENY/REVIEW),
confidence, reasoning,
RecommendedAction (BLOCK/ALLOW/LOG/ALERT),
policy_version, evaluated_by
```
Populated by [[Detection Engine#Kairos]] policy engine.

## Relationships

```
related_signals[]   // ULID refs to correlated signals
incident_id         // FK to PostgreSQL incidents table
session_id          // L10 session grouping
conversation_id     // conversation thread grouping
user_id             // end-user identity
```

```
provider { name, model, model_version, region }
```

## Signal Categories

Defined in `proto/argus/v1/categories.proto`, `gen/go/argus/v1/categories.pb.go`

| Range | Layer | Examples |
|-------|-------|---------|
| 101–199 | L1 Hardware | INFRA_CPU_SPIKE, INFRA_MEMORY_PRESSURE |
| 201–299 | L2 Model | MODEL_LOAD, MODEL_HASH_CHANGE |
| 301–399 | L3 Tokenizer | TOKENIZER_TRUNCATION, TOKENIZER_VOCAB_MISMATCH |
| 401–499 | L4 Transformer | INFERENCE_KV_CACHE_HIT, INFERENCE_ATTENTION_ANOMALY |
| 501–599 | L5 Output | OUTPUT_COMPLETION, OUTPUT_REFUSAL, OUTPUT_LOGPROB_DROP |
| 601–699 | L6 Safety | SAFETY_BLOCK, SAFETY_POLICY_VIOLATION |
| 701–799 | L7 RAG | RETRIEVAL_SEARCH, RETRIEVAL_EMBED, RETRIEVAL_LOW_SCORE |
| 801–899 | L8 Agents | AGENT_TOOL_CALL, AGENT_PERMISSION_ESCALATION |
| 901–999 | L9 Gateway | GATEWAY_REQUEST, GATEWAY_RATE_LIMITED |
| 1001–1099 | L10 App | APP_SESSION_START, APP_USER_MESSAGE, APP_COMPLETION |
